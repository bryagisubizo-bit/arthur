# Language Community and Vitality Sources

Arthur’s language catalogue is descriptive. It must not infer fluent support, invent colloquial expressions, or label a language’s vitality without an appropriate current community or authoritative source.

| Subject | Source | Implementation boundary |
| --- | --- | --- |
| Diné Bizaad (Navajo) | [Navajo Nation Executive Order No. 01-2025](https://opvp.navajo-nsn.gov/executive-order-no-01-2025-dine-bizaad-official-language-of-the-navajo-nation/) | Display the endonym **Diné Bizaad**, ISO code `nv`, and a community-governance/review state. Do not call it extinct, invent vocabulary, or imply automatic voice, translation, or search support. The order records its designation as the official language of the Navajo Nation. |
| Language vitality and documentation | [UNESCO, *Towards World Atlas of Languages*](https://www.unesco.org/en/articles/towards-world-atlas-languages) | Treat vitality information as context-dependent and potentially incomplete. Use “authoritative community source required” where a current designation cannot be responsibly verified; do not equate limited technical support with language vitality. |

Arthur intentionally ships no colloquial/slang expressions for any language. A future entry requires a community-approved source, regional context, a usage note, a review state, and a user-visible provenance record.
