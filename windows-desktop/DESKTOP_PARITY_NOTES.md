The Updates workspace visibly states that there is no background polling and separates the manual release-metadata action from source configuration. It shows the configured `owner/repository` source, optional private-token field, manual-only lock, and clear no-download status before any network request. The `Check GitHub Releases now` action is visually distinct, while the first-run tutorial remains available on demand without requiring a new installation.

## Desktop-specific boundary

The Windows prototype preserves local-only safe behavior. It shows provider-dependent and Windows-adapter states rather than claiming live provider actions, arbitrary PC control, or automatic security functions. PyInstaller packaging and Inno Setup compilation must still run on a Windows 11 machine.
